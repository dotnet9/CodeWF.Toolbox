# 12.0.11 界面对照与验证边界

审计日期：2026-10-15。实际应用使用 Avalonia Headless + Skia，单文件 HTML 使用 headless Chromium；截图均为 1280×840、1×。桌面保持锁定，未打开普通应用窗口或安装器。

本轮没有证明整体还原度达到 95%。下列测量用于定位差异，不将相同背景面积或平均像素误差换算为视觉还原百分比。

## 相同场景与测量

两侧使用 .NET 紫、跟随系统的浅色结果，打开 Base64 与大小写两个文档，激活 Base64，输入 `Independent 中文 😀` 并实际编码。分别捕获简体中文和英文。对照图左侧为 HTML，右侧为真实应用；另生成四倍亮度的 RGB 绝对差异图，保留完整标题栏。

| 场景 | 平均 RGB 通道绝对差异（0–255） | 完全相同的像素占比 |
| --- | ---: | ---: |
| 简体中文 | 6.9611 | 87.2579% |
| 英文 | 6.7321 | 87.2458% |

大面积同色背景会提高完全相同像素占比；上述占比不代表功能覆盖率或视觉评分。浏览器字体、原生窗口装饰和控件模板也会产生像素差异。

## 自动验证与复现

- 纯算法测试 5 项：独立字段/结果状态、Unicode 与 URL-safe Base64、JSON 精度与压缩。
- 实际 UI 托管验证 200 项：117 入口元数据、13 自定义页面、真实 Base64、指针拖动 GridSplitter、真实 Dock 分屏、分屏后关闭和重开、区域及缓存清理、主题、语言与关于。
- Windows NativeAOT UI 验证器执行相同 200 项，明确输出 `NativeAOT=True`；正式 `CodeWF.Toolbox.exe --verify-runtime` 独立运行成功，明确输出版本 `12.0.11.0`，确认发布资源、英文资源和 Unicode Base64。两种验证分别运行，不互相替代。
- 更新使用 IUpdateService 假对象覆盖检查/下载/校验/安装失败、重试、资产缺失回退、取消与释放，没有启动真实安装器。
- HTML 仅将 index.html 复制到空目录后验证：13 分类、独立草稿、并排、双语、16 主题快照、偏好重载及更新失败重试/取消，零外部请求和 JavaScript 错误。
- 发布资产检查覆盖五安装包及其 SHA-256；额外便携压缩包、篡改校验和缺失文件均必须被拒绝。
