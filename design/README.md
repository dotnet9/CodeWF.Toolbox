# 离线界面原型

将 index.html 单独复制到空目录，用浏览器打开即可。HTML 内嵌所有代码、双语文案、logo 和 16 套共享主题令牌，不需要服务器或外部网络。

- 13 分类与 117 工具入口来自真实应用导出的 tool-manifest.json；参数类型、选项和默认值保留。
- Ribbon、独立文档、切换保留草稿、拖动排序、并排两栏、属性分隔线、搜索、主题、语言和关于均可交互。
- Base64、JSON、UUID、大小写、URL 和 SHA-256 提供代表性本地计算。其他工具展示明确演示反馈；文件、网络和完整算法仍由桌面模块执行。
- 更新使用模拟状态，包括资产缺失、失败、重试、进度和取消；不会下载安装器。

维护原型：node scripts/build-prototype.cjs。验证生成文件：node scripts/build-prototype.cjs --check。
