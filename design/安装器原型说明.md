# CodeWF.Toolbox 安装器交互原型

直接打开 [CodeWF.安装器原型.html](CodeWF.安装器原型.html)。本文件的默认产品为 **CodeWF.Toolbox**，内嵌版本快照为 **12.0.19**。

## 单仓独立维护

HTML 内嵌全部 CSS、脚本与 SVG；只拉取本仓库即可离线双击打开，不读取邻仓文件，也不依赖本仓主应用原型。此原型与 `index.html` 或其他主应用原型分别维护，修改安装器原型不会覆盖主应用。

各产品仓库的文件是独立快照，没有运行时共享、自动同步或覆盖机制。统一设计变更可以人工审查后复制，每仓仍独立维护。更新本产品时修改文件内的 `prototypeConfig.repository`、`prototypeConfig.defaultProduct`，以及 `products` 中对应产品的 `version`、文案和安装策略。其余产品保留为评审选项；所有版本都是内嵌快照。HTML 不是生产安装器的构建输入，不会自动改变安装脚本或发布版本。

品牌为 **CodeWF**，**码坊** 作为辅助品牌，页头及核心品牌可点击打开 <https://codewf.com>。`.NET` 仅作为技术栈信息，`.NET` 紫 `#512BD4` 作为配色，不作为产品名称。保存文件使用 UTF-8，保留单文件交付。

## 视觉与交互

Windows 保留已确认的异形窗口轮廓、紫色部署舱、核心、轨道环和粒子。主题支持浅色、深色、跟随系统；界面可切换简体中文与英文。切换步骤、主题或语言时保留核心、轨道与 Canvas 实例；更新进度不重建旋转图标。粒子速度平滑改变，页面内容不做整块透明闪现，完成反馈不把整环放大到消失。

系统“减少动态效果”和页面同名开关均能停止循环动效，保留可读状态与进度。页面隐藏、窗口关闭或最小化时暂停 Canvas；只有一个绘制循环。

- Windows：欢迎、MIT 许可、位置和安装范围、快捷方式、确认、进度、完成，以及维护、卸载、错误、重试与取消确认。可选项以文件内产品策略为准；Vex 另有 Markdown 打开方式候选。
- macOS DMG：Finder 模型，支持拖放应用到 Applications，也可聚焦应用图标后按 Enter，演示复制、替换和推出。PKG 是单独的可选提案。
- Linux DEB：系统软件管理器的包详情、授权、安装和移除；不虚构自选安装目录与范围。

## 本仓验收

先确认首次打开选中本仓产品、显示上面的版本；切换两种语言和三种主题，点击“预览安装特效”，再重置并按步骤走完整安装流程。检查许可门禁、无效路径、目录选择、产品安装范围、维护、错误重试与取消确认；再检查 DMG 拖放、替换提示、DEB 授权，以及减少动效、Tab、Enter、Escape 和 Alt+左方向键。

同时确认品牌链接为 `https://codewf.com`，下拉框文字左对齐，窗口切角透明且操作区无横向裁切。可将这一个 HTML 单独复制到空目录复测，以验证独立性。

进度、空间、账户、目录及错误场景为模拟数据。密码输入为只读示例，不收集密码。除用户主动点击官网链接外，页面不发网络请求，不访问磁盘、注册表或安装服务，不写本地存储。原型不证明真实系统安装、提权、签名、公证、卸载或多 DPI 已验收；macOS Finder 与 Linux 软件管理器的真实外观由操作系统控制。
